# USA Job Application Marketing — Dinesh Yadav

Production-ready marketing website + booking backend for candidates targeting USA contract and full-time roles.

## Included

- Premium blue responsive website in HTML/CSS/JS
- Animated 10-step candidate marketing process
- Candidate booking form
- Live booking availability generated by backend
- SQLite persistence
- Double-booking protection
- Protected admin booking dashboard at `/admin`
- Booking status workflow: new → confirmed → completed / cancelled
- `.ics` calendar event endpoint for every booking
- Optional SMTP email notification to `dineshmca500@gmail.com`
- Optional WhatsApp confirmation link
- Helmet security headers + API rate limiting
- Environment-based configuration

## Local setup

```bash
npm install
cp .env.example .env
# fill SMTP and admin values
npm start
```

Open `http://localhost:3000` and `http://localhost:3000/admin`.

## Hostinger VPS deployment

1. Install Node.js 20+ and Git.
2. Clone the repository.
3. Run `npm install --omit=dev`.
4. Copy `.env.example` to `.env` and set a strong `ADMIN_TOKEN`.
5. Set `BASE_URL` to the real HTTPS domain.
6. Set `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, and `SMTP_FROM` if email notifications are required.
7. Set `WHATSAPP_NUMBER` to Dinesh's business WhatsApp number in international format without `+` (for example `9198xxxxxxxx`).
8. Start with `npm start`; use PM2 for production:

```bash
npm install -g pm2
pm2 start server.js --name marketing-booking
pm2 save
pm2 startup
```

9. Put Nginx/Apache in front of Node and proxy the domain to `127.0.0.1:3000`.
10. Enable SSL and force HTTPS.

## Important production notes

- Never commit `.env` or real SMTP passwords.
- Replace the example admin token before launch.
- The booking timezone is `America/New_York` (ET).
- The current slot list is defined in `server.js`; update it if Dinesh wants different working hours.
- SQLite is suitable for a single VPS deployment. For high traffic or multiple application servers, move the booking table to PostgreSQL.
